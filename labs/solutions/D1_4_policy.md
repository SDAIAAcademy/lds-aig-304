# المختبر 1.4 · سياسة الذكاء الاصطناعي لمطايا
> الحل المرجعي للمدرب.

| السطر | الحكم |
|---|---|
| P1 | يُعاد صوغه: «أخلاقيًا» بلا معنى حتى تُسمّى المبادئ (C5) |
| P2 | يُحذف: شعار تسويقي لا التزام |
| P3 | ينتقل إلى إجراء الإصدار P-03: رقم وعتبة |
| P4 | يبقى: يذكر المبادئ ويغطي ما تبنيه وتشتريه وما يبنيه الموظفون (C1، C5) |
| P5 | ينتقل إلى إجراء الحوادث P-09، ويبقى في السياسة التزام عام بالإبلاغ |
| P6 | يبقى: مبدأ المراجعة البشرية للقرارات التي تمس الناس |
| P7 | يُعاد صوغه: منع شامل لا يُطبَّق؛ يحل محله سجل الأدوات وقاعدة البيانات العامة |
| P8 | يبقى: إطار وضع الأهداف (C2) |

بنود القائمة التي لا يغطيها أي سطر:
- C3: التزام بالوفاء بالمتطلبات المنطبقة.
- C4: التزام بالتحسين المستمر.
- C6: الإحالة إلى سياسات الخصوصية وأمن المعلومات والمشتريات والموارد البشرية.
- C7: المالك والاعتماد ومدة المراجعة.
- C8: التبليغ والإتاحة.

نص مقترح للالتزامات الناقصة: «تلتزم مطايا بالوفاء بالمتطلبات النظامية والتعاقدية المنطبقة على أنظمة الذكاء الاصطناعي التي تطورها أو تقدمها أو تستعملها، وبالتحسين المستمر لنظام إدارتها. تتسق هذه السياسة مع سياسات الخصوصية وأمن المعلومات والمشتريات والموارد البشرية. تملكها رئيسة مكتب حوكمة الذكاء الاصطناعي، وتعتمدها الرئيسة التنفيذية، وتُراجع كل سنة في مراجعة الإدارة، وتُبلَّغ لكل الموظفين وتُتاح لعملاء الشحن عند الطلب.»

قاعدة مطايا لأدوات الموظفين (ليست نصًا وطنيًا): «لا يدخل أي أداة ذكاء اصطناعي توليدي إلا ما صُنّف عامًا»، على غرار مبادئ سدايا للجهات الحكومية التي تمنع إدخال ما صُنّف مقيدًا فأعلى.
